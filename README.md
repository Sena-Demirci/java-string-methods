# Java String Methods ☕️

Java OOP öğrenirken aldığım küçük String method notları.

Bu repo hem kendi tekrarlarım için hem de arkadaşlarım lazım olduğunda açıp bakabilsin diye hazırlandı. Çok profesyonel bir kaynak değil; daha çok **öğrenciden öğrenciye kısa notlar** gibi düşünün.

İçeride bazı methodların hazır kullanımını, bazılarını da mantığını anlamak için manuel olarak nasıl yapabileceğimizi görebilirsiniz.

`length()` · `charAt()` · `substring()` · `equals()` · `contains()` · `indexOf()` · `trim()` · `replace()` · `isEmpty()` · `split()` · `toUpperCase()` · `toLowerCase()` · `startsWith()` · `endsWith()`
